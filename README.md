Project Description
This repository contains a Digital Evidence Management System designed to log, track, and manage investigation cases and associated digital evidence. To demonstrate a broad understanding of software engineering concepts, the system was developed using two distinct architectural approaches:

Java Version: Focuses on Object-Oriented Programming (OOP) principles to create a scalable and well-structured application.

C++ Version: Emphasizes low-level memory management and algorithmic logic by implementing data structures (such as Stacks) manually from scratch, alongside persistent File I/O operations, without relying on built-in standard libraries.
